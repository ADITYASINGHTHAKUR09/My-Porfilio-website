# Aditya Thakur — AI Portfolio

A responsive, dark-tech personal portfolio built with plain HTML, CSS and JavaScript.

## Features

- Responsive layout and mobile navigation
- Experience, projects, skills and education sections
- Scroll reveal animations with reduced-motion support
- Contact form that prepares an email in the visitor's email application

## Local preview

Open `index.html` directly or run:

```bash
python3 -m http.server 8080
```
